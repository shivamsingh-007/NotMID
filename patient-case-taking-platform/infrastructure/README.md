# Infrastructure

Structure infrastructure by reusable modules and explicitly promoted environments.

- `environments/local`
- `environments/dev`
- `environments/staging`
- `environments/production`
- `modules/network`
- `modules/edge`
- `modules/compute`
- `modules/data`
- `modules/messaging`
- `modules/observability`
- `modules/secrets`
- `kubernetes/base`
- `kubernetes/overlays`
- `runbooks`

Infrastructure selection remains cloud-neutral until availability, residency, cost and facility-connectivity requirements are approved.
